# Reference Screenshots

Store Fairdeal Market screenshots and other approved visual references in this directory.

## Recommended organization

Use descriptive filenames and, when useful, subdirectories by workflow:

- `login/`
- `catalog/`
- `product-details/`
- `cart-and-checkout/`
- `orders/`
- `account/`

Keep the original image unchanged. Add context in a companion Markdown file when a screenshot needs explanation, including source, date received, intended workflow, and observations. Screenshots are references, not proof of existing POS behavior or final design requirements.
